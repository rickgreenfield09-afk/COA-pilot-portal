# coa-employee-portal
Employee self-service portal for Cyber Offset Alliance — Azure Static Web App frontend with Functions API backend.

Internal employee self-service portal for Cyber Offset Alliance.

## Stack
- Frontend: Plain HTML/CSS/JS (no framework, no build step)
- Hosting: Azure Static Web Apps
- API: Azure Functions (C#/.NET)
- Database: Azure Database for PostgreSQL Flexible Server (with Row-Level Security)
- File storage: Azure Blob Storage
- Auth: Entra ID (Microsoft identity platform)

## Branch Strategy
- `main` — production. Protected; changes only land here via reviewed pull request.
- `dev` — active development. Work happens here day to day.

## Status
In active build. Not yet deployed to production.
